# Veanthan Maths Academy Website

A responsive, premium green-and-gold tuition academy website built with plain HTML, CSS, and JavaScript. No build step or framework is required.

## Features
- Responsive desktop, tablet, and mobile layouts
- Emerald-green and gold brand styling
- Scroll reveal animations and floating mathematics decorations
- Sticky navigation and animated mobile menu
- Class enquiry buttons that open WhatsApp
- Enquiry form validation that prepares a WhatsApp message
- Click-to-call and email links
- Faculty profile and resume-based teaching experience timeline
- Reduced-motion accessibility support
- SEO and social metadata

## Run locally
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.

For a local development server, open a terminal in this folder and run one of:
- `python -m http.server 8000` then visit `http://localhost:8000`
- VS Code: use the Live Server extension.

## Deploy
Upload the contents of this folder to a static hosting service such as GitHub Pages, Netlify, or Vercel.
